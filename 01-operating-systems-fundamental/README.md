## 💻 مقدمه ای بر سیستم عامل
سیستم عامل یک برنامه سیستمی است که مدیر سیستم است. سیستم عامل یک لایه نرم افزاری است و نزدیک ترین لایه به سخت افزار است یعنی OS که بیشترین درک را نسبت به سخت افزار دارد. OS یک لایه است بین Applications و Users و Hardware که OS نقش مدیریتی دارد. این نقش برای لایه بالا که قرار است Applications را خوب مدیریت کند و یک نقش برای لایه پایین که قرار است Resource را مدیریت کند ، به این ترتیب لایه میانی OS که نقش مدیر را دارد هم از لایه پایین و هم از لایه بالا مراجعه کننده دارد. سخت افزار یا Hardware به مجموعه ای از Resource ها گفته می شود.

<img width="100%" height="576" alt="image" src="https://github.com/user-attachments/assets/fbf2b2b1-12ef-43a5-a4c4-2ec3ceb2cc4d" />

در این شکل OS یک لایه واسطه است که از پایین با سخت افزار های سیستم در ارتباط است و از بالا با Applications و Users در ارتباط است. سیستم عامل 2 لایه بالا و پایین خود را مدیریت می کند.

حالا یکسری سوال پیش می آید : 

- سیستم عامل چیست ؟ 
- انتظاراتی که از یک OS وجود دارد چیست ؟ 
- چرا به OS نیاز داریم ؟ 
- وظایف و خصوصیات OS چیست ؟

### 1) سیستم عامل یک واسطه است بین Hardware و Application و Users ، یعنی چی ؟

یعنی  Applications و Users اگر میخواهند از Resource استفاده کنند باید از OS این را درخواست کنند و OS این ارتباط را برایشان بر قرار می کند ، به این دلیل که کارکردن با منابع یک سیستم کامپیوتری کار پیچیده است است و کار User عادی با Application نیست ، OS این کار را انجام می دهد تا دیگر User یا Application درگیر جزئیات و پیچیدگی های استفاده از سخت افزار نشود.

#### تعریف Deriver : 

درایور نرم افزاری است که درون سیستم عامل قرار دارد و زبان کنترلر مربوط به خودش را میشناسد و میتواند تنظیمات مربوط به آن منبع راانجام دهد ، چون Driver هر منبع را شرکت سازنده آن منبع ارائه کرده است.

### 2) مدیریت بهینه Resource :

سیستم عامل دو لایه را مدیریت می کند شامل لایه Application و لایه Hardware در جهت استفاده کار آمد Resource ها. از منابعی که در سیستم وجود دارد مثل memory و disk و  cpu و ... چگونه و به چه نحوی استفاده کنیم بطوریکه منابع خوب و بهینه استفاده شوند و هدر نروند.

### 3) مدیریت و پاسخ به نیاز های User ها و Applications :

در نظر گرفتن و توجه اولویت و اهمیت بین آنها ( برآوردن مطلوب نیاز کاربران ) . مثلاً وقتی میخواهیم CPU را به برنامه های مختلف بدهیم از چه الگوریتم زمانبندی استفاده کنیم.

### سیستم عامل Linux

در linux و unix همه چیز را به صورت file می بینیم حتی device ها و همه ی سیستم عامل یک هسته یا kernel دارند که اجازه می دهد با سخت افزار سیستم ارتباط بر قرار کنند و برای برقراری ارتباط با kernel از Shell استفاده می شود این Shell می تواند به صورت CLI و GUI استفاده شود.
