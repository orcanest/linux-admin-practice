---
### 🎯 Target

هدف اصلی این ریپو تبدیل دانش تئوری Linux به **مهارت عملی در System Administration** است  و در هر مبحث :

- ابتدا مفاهیم و نکات اصلی را مطالعه می‌ کنم.
- دستورات و ابزارهای مرتبط را در محیط آزمایش اجرا می‌ کنم.
- سناریوهای عملی مختلف را حل می‌ کنم.
- مشکلات و خطا های احتمالی را بررسی و Troubleshoot می‌ کنم.
- نتیجه و تجربه‌ ی به‌ دست‌ آمده را document می‌ کنم.
- برای سناریو های منتخب ، اجرای عملی را به‌ صورت ویدیو ضبط می‌ کنم.
